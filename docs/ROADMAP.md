# Membuy: ежедневные улучшения

Каждый день автоматическая задача берёт **первый невыполненный пункт** (`- [ ]`), делает его, проверяет тестами,
отмечает `- [x] (дата)` и публикует. Владелец может менять порядок, вычёркивать и добавлять пункты в любой момент.

## Правила
- Один пункт за запуск. Небольшие, законченные изменения.
- Код, который двигает деньги, **не трогать без отдельного разрешения владельца**: `js/swap.js`, `js/fees.js`, `js/referral.js`,
  `js/send.js`, `js/pumpcreate.js`, `js/adchain.js`, `js/wallet.js`, `js/config.js`, `worker/*`. Если пункт требует их изменить —
  пропустить его с пометкой `(нужно разрешение)` и взять следующий.
- Перед публикацией: `node build/build.js`, `node build/test.js`, `node build/test_live.js`, `node build/test_i18n.js` — всё зелёное.
  Для новой функции добавить проверку в тесты.
- Весь новый текст интерфейса — на русском в коде и с английским переводом в `js/i18n.js` (тест перевода должен быть «Перевод полный»).
- Без обещаний прибыли, без выдуманных цифр, без логотипов чужих компаний.

## План
- [ ] Проверка риска на странице монеты: карточка «5 тревожных признаков» (доля топ-10 держателей, ликвидность, возраст, соцсети, похожий тикер) с цветом зелёный/жёлтый/красный.
- [ ] Поиск по адресу монеты: вставил адрес в поиск — сразу открывается монета.
- [ ] Ценовые оповещения: «сообщить, когда цена выше/ниже X» (хранятся в браузере, уведомление в приложении и системное, если разрешено).
- [ ] Распределение держателей на странице монеты: полоска топ-10 / остальные.
- [ ] Скелетоны загрузки вместо «Загружаем…» на рынке, монете и в профиле.
- [ ] Карточка прибыли/убытка позиции для «Поделиться» (картинка с логотипом Membuy, без обещаний).
- [ ] Круговая диаграмма портфеля в профиле.
- [ ] Экспорт истории сделок в CSV.
- [ ] Светлая тема с переключателем в настройках (по умолчанию — как в системе).
- [ ] Раздел «Выпущено на Membuy»: монеты, созданные через наш сайт.
- [ ] Виджет «Топ роста за час» над списком монет.
- [ ] Реакции на посты в ленте (🔥 👍 😂) с подсчётом.
- [ ] Сравнение двух монет на одном графике.
- [ ] Горячие клавиши на компьютере (/, Esc, B, S).
- [ ] Ленивая загрузка графика и тяжёлых модулей: быстрее первый экран.
- [ ] Проверка доступности (контраст, подписи, фокус) и исправления.
- [ ] Обучающий тур для живого режима: подключение Phantom, первая покупка, безопасность.
- [ ] Центр уведомлений: группировка и «прочитать все».
- [ ] Архитектура: разбить самые длинные модули на части, добавить JSDoc-типы к общим функциям.
- [ ] Страница «Что нового» со списком улучшений по дням.
