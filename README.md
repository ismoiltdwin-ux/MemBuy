# Membuy

Терминал для покупки и продажи мемкоинов Solana. Работает в браузере, без сервера.

## Запуск

```bash
cd membuy
python3 -m http.server 8080     # затем откройте http://localhost:8080
```

После правок в `build/body.html` или списке модулей: `node build/build.js`.

## Проверка

```bash
node build/test.js        # 112 проверок демо-режима, нужен Playwright
node build/test_i18n.js   # проверка перевода: все экраны на английском и таджикском
```

## Языки

Русский, английский и таджикский. Переключатель — внизу каждой страницы и в настройках.
Переводы лежат в `js/i18n.js`. Чтобы добавить язык, допишите его в `LANGS` и добавьте перевод в конец каждой строки словаря.

## Режимы

- **demo** (по умолчанию) — выдуманные монеты и учебные сделки, 5 условных SOL. Деньги не используются.
- **live** — реальные монеты и сделки через Phantom и Jupiter. Включается в `js/config.js`: `MODE: 'live'`.

## Перед включением live

Live-код написан по документации API и **не проверен на реальных сделках**. Нужно:

1. Выложить сайт на хостинг с HTTPS (кошельки не работают с `file://`).
2. Проверить покупку и продажу на маленькой сумме со своего кошелька.
3. Заменить публичный `RPC_URL` на собственный (Helius, QuickNode и т.п.) — публичный ограничивает запросы.
4. Для комиссии: создать реферальный аккаунт Jupiter и вписать его в `FEE_ACCOUNT`.
5. Проверить требования закона вашей страны к криптосервисам.
6. Добавить страницу с условиями использования и предупреждением о рисках.

Подробности устройства — в `ARCHITECTURE.md`.

## Сервер-посредник для выпуска монет

`worker/upload-worker.js` — Cloudflare Worker `membuy-upload`: загружает картинку и описание монеты в IPFS (Pinata).
Cloudflare собирает его из этого репозитория автоматически при каждом изменении в ветке `main` (настройки — в `wrangler.jsonc`).
Секрет `PINATA_JWT` хранится только в Cloudflare (Settings → Variables and Secrets).
